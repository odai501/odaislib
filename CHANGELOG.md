# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.11.16] - 2026-07-23

### Added
- Initial release
- Full Facebook integration (basic, auth, mobile, blockslogin)
- Instagram support (login, checkusername, info, date, search)
- Email checking for Gmail, Yahoo, Outlook, AOL, GMX, hi2.in
- Steam, Roblox, Threads, Telegram, Kick integrations
- Utility classes: Proxy, recaptcha, weather, pipinfo, file2link, namefromphone
- Outlook advanced features (profile, keyword search)

### Security
- Added ethical warning in README
- All functions respect terms of service
